# Obsidian 知识工作台

把新资料和对话续聊整理成可复用的知识，保存为本地 Markdown，在 Obsidian 或网页里找回做法、核对来源、继续工作。

**当前版本：v0.5.1 · Windows · 本机优先。** 仓库提供程序和规则，不包含个人笔记、账号授权或已经配置好的定时任务。

## 能用来做什么

- **找回做法**：按“项目 + 具体问题”检索笔记，查看带来源的回答。
- **继续工作**：选择相关资料，生成含已有决定、未完成事项和来源的接续内容。
- **收录新增**：点击“自动总结”先选新增对话；需要时加入并勾选本机资料，旧内容跳过。
- **整理知识**：具体标题、一句话概括、项目／方法／资料分类；重复主题合并，原件与来源身份保留。
- **离线与迁移**：笔记可直接用 Obsidian 打开；网页导出、导入迁移包，保留附件、图谱设置和增量记录。

## 开始使用

需要 Windows、Python 3.11+（含 Python Launcher）和 Node.js 22.13+。阅读、检索和迁移不需要模型；AI 整理需要自己的 Codex CLI 登录，读取对话还需要正在运行的 Codex 桌面工具上下文。

下载 [Windows 启动包](https://github.com/zhangzeyu99-web/file-management-assistant/releases/latest/download/Obsidian-Workspace-Windows.zip)，解压到可写目录。

**已有知识库迁移包：** 双击 **打开工作台.cmd** → “备份与迁移”选 ZIP → 预检 → “导入并使用”。下次启动继续打开已导入的库，不重总结历史资料。

**首次建立空库：** 在解压目录执行一次明确的初始化命令，再双击启动：

```powershell
py -3 -X utf8 scripts/setup_workspace.py --config config.local.json
```

初始化建立空库和从当前时刻开始的增量基线，拒绝覆盖已有配置、笔记或检查点。已有资料库应通过迁移导入。需要收录哪些文件夹，再在生成的私有配置中填写 `watch_roots`；默认不扫描个人目录，飞书默认关闭。

本机默认打开 `http://127.0.0.1:5174/`。在 Obsidian 中选择“打开本地仓库”，打开配置里的 `obsidian_vault`，从 `00 入口/知识库首页` 阅读。

## 每次归档遵守同一份标准

[归档入库规则](docs/ARCHIVE_RULES.md) 是手动收录、增量更新、主题合并和周任务的共同标准；[AGENTS.md](AGENTS.md) 要求执行者每次先读。引擎共用内容准入、标题和正文门禁；只有来源登记的内容不生成知识节点。

- 标题必须说清对象和问题；第一段一句话概括，再展开必要事实。
- 只积累以后能复用的知识。提醒、检查流水、空登记、临时脚本和安装包只留私有来源记录。
- 同主题去重并保留最新有效结论；旧原文隐藏归档，来源、旧链接和处理身份继续有效。
- 已处理内容跳过；截断、失败、运行中的轮次保留未完成，成功写入并读回才登记。

配置完成后，在网页点“自动总结”查看候选并确认；默认只选用户新增／续聊，不扫描本机文件或飞书。[每周归档](docs/WEEKLY_ARCHIVE.md) 提供队列、复核和验收入口，以及在自己的 Codex 中设置周五 19:00（北京时间）任务的方法。**克隆或换机不会自动创建定时任务。**

## 本机和线上

本机执行器负责读取资料、调用模型、写入与同步；线上是登录保护的阅读副本和持久任务队列。电脑离线时可以阅读已有副本，更新任务等待本机恢复。需使用自己的站点及授权，见 [部署说明](docs/DEPLOYMENT.md)。

迁移包包含知识文件和增量状态，不包含登录凭据或原始对话数据库。新机器重新授权后可继续处理新增，详见 [迁移说明](docs/MIGRATION.md)。

## 来源与能力边界

| 来源 | 当前处理方式 |
|---|---|
| 文本、Markdown、DOCX、文字层 PDF | 明确勾选或上传后处理；自动候选排除空文件、仓库说明和运行产物 |
| Codex 对话 | 官方原生接口读取新完成轮次；保留逐轮去重和未完成状态 |
| 飞书（可选） | 保留旧入口记录；不作为默认自动总结来源 |
| 音视频、图片、工作簿 | 先通过对应专项流程处理，再收录文本结果 |

检索使用项目别名、关键词、问题意图和 Markdown 段落索引，查找后即可阅读资料；需要时点击“AI 整理答案”，基于前六条相关资料回答。没有向量检索，也不会自行联网补答案。官方线程接口仍有超长内容与活跃列表窗口限制，未覆盖来源会明确保留。

## 从源码运行与维护

```powershell
git clone https://github.com/zhangzeyu99-web/file-management-assistant.git
cd file-management-assistant
py -3 -X utf8 scripts/setup_workspace.py --config config.local.json
.\打开工作台.cmd
```

已有迁移包时跳过初始化。启动器准备依赖；开发者也可先安装依赖，再运行 `start.ps1 -Config <自己的配置>`。配置优先级及线上构建见部署说明。
