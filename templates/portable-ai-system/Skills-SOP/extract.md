# SOP：生成 AI 上下文包

类型：Skills / SOP
来源：本地知识整理助手初始化模板

## 目标

把当前任务需要的已整理证据压缩成可复制给 AI 的 prompt。

## 流程

1. 先用搜索回顾找到候选来源。
2. 展示候选来源和相关原因。
3. 用户确认来源后再生成 Markdown 和 prompt。
4. prompt 必须包含来源路径、压缩摘要、安全边界和下一步请求。
5. 无候选证据时拒绝生成上下文包。

## 验收

- prompt 可直接复制给新的 AI 对话。
- prompt 中的每段上下文都有来源路径。
- 不混入无关旧报告或未确认来源。

## 下一步

- 把 prompt 交给新的 AI 对话。
- 新任务完成后，将结果重新添加资料入库。
