# 把知识工作台迁到另一台 Windows 电脑

日常迁移在网页完成：旧电脑导出一个 ZIP，新电脑打开工作台，选包导入。不需要手写路径映射或运行命令。整理后的主题、具名依据、`.source-history` 原文档案及旧链接映射一并保留；原始档案不会重新成为普通图谱节点。

## 旧电脑：导出迁移包

1. 在本机或线上工作台打开 **备份与迁移**，点击 **导出迁移包**。
2. 等待准备完成，再点 **下载迁移包**，把 ZIP 保存到自己的设备。准备期间不要编辑笔记。
3. 把下载好的 ZIP 带到新电脑，原知识库继续保留。

网页导出不需要手动停止执行器。线上导出依赖旧电脑的执行器：旧电脑离线时显示等待，连接恢复后才会处理，不会把排队当作导出完成。

线上迁移包上限为 **128 MiB**，下载链接 **24 小时内有效**；过期后重新导出。链接过期不代表服务器上的文件已经物理删除。较大的包可在旧电脑的本机页面导出；新电脑网页一次可接收的 ZIP 上限为 **2 GiB**。

## 新电脑：解压、双击、导入

1. 先安装 **Python 3.11 或更高版本（含 Python Launcher）**、**Node.js 22.13 或更高版本**。
2. 下载 [最新版 Windows 启动包](https://github.com/zhangzeyu99-web/file-management-assistant/releases/latest/download/Obsidian-Workspace-Windows.zip)，完整解压到准备长期保留的目录。
3. 双击 **打开工作台.cmd**。启动入口会自动准备项目依赖并打开网页；首次准备依赖需要网络，无须手动运行安装命令。
4. 首次使用会进入 **备份与迁移**。点击 **选择迁移包**，选择旧电脑导出的 ZIP，等待上传和预检。
5. 核对笔记数、已处理来源数及 **存放位置**。默认使用独立的新目录；可以修改位置，再点 **检查新位置**。
6. 点击 **导入并使用**。完成后自动进入新知识库首页，可以直接阅读和检索。

以后再次双击同一份 **打开工作台.cmd**，会打开上次导入的知识库。启动本身不会自动发起整理，也不会创建空检查点。

如果这台电脑已有知识库，导入会切换到独立的新库，原有资料和配置仍留在原位置。已有任务正在执行时，先等任务结束。目标目录冲突会明确提示，不覆盖人工文件。

### 如果你现在打开的是线上站点

线上页的 **在这台电脑打开工作台** 指向当前电脑的本机页面，不会把迁移包导入旧电脑的在线执行器。新电脑尚未启动工作台时，先下载启动包、解压并双击，再从本机页面选择 ZIP。

## 包里有什么

- 知识库内可迁移的 Markdown 笔记和附件，保留正文、修改时间及相对链接。
- 已处理文件、对话轮次、飞书来源等增量记录，以及失败和待处理边界。
- 成功回执、来源检查记录，以及接续所需的基线时间。
- 已启用的主题布局、旧笔记链接映射、隐藏任务身份记录及原生图谱的分类颜色、筛选与外观设置，使新机器继续使用相同入口及重试规则。

新旧路径自动映射到所选位置，已总结来源不会仅因换盘符再次入队。检索索引从已有笔记重建，不会重新调用模型写历史摘要。Markdown 正文中写过的旧绝对来源路径保留原样；站内笔记阅读不受影响。

不会携带登录凭据、原始 Codex 会话数据库、待执行任务、上传暂存、模型缓存或 Obsidian 插件设置。软件安装包（APK、EXE、MSI、DMG、ISO、APPX、MSIX）排除；ZIP/RAR 文档附件保留。监控目录中的原始文件不随包复制，需要时另行搬迁并核对来源目录。仅阅读已整理笔记不需要这些原件。

迁移包包含个人资料，请自行保管，不要提交到公开代码仓库。

## 遇到中断怎么办

- **上传中断或选错文件**：取消上传后重新选择，尚未确认的包不会导入。
- **文件损坏、格式不符或目标冲突**：按页面提示换包或修改存放位置，再预检。
- **已恢复资料，但启用失败**：点击 **重试启用工作台**，沿用已恢复的资料，不重复导入。
- **提交后暂时断开连接**：先检查本次进度，不重新创建另一份导入。页面会区分未确认、未完成和已启用。

导入成功后，搜索一个熟悉的问题、打开一篇来源，确认读到旧笔记。继续 AI 整理需要新电脑自己的 Codex 登录；读取原对话还需要原生接口能访问相应对话，并从 Codex Desktop 当前工具上下文启动执行器。迁移包不复制对话数据库，也不保证新电脑自动拥有旧对话。飞书来源需重新授权。

导入默认关闭线上连接。需要接回同一线上队列时，先停用旧机执行器，再按 [部署说明](DEPLOYMENT.md) 配置新机服务令牌，不让两台电脑同时写同一库。

## 命令行兼容入口

已有脚本仍可使用 `scripts/migrate_workspace.py` 的 `export`、`inspect`、`import` 命令。手动 CLI 导出前需通过 `stop.ps1` 正常停止执行器；网页导出不需要这一步。

```powershell
py -3 -X utf8 scripts/migrate_workspace.py --help
py -3 -X utf8 scripts/migrate_workspace.py inspect --bundle "E:\PrivateBackup\knowledge.zip"
```

CLI 导入接收自己的 `from/to` 绝对路径映射 JSON，可先加 `--dry-run` 预检，再导入到独立目录。缺失映射、已有不同内容或运行目录冲突都会拒绝，不初始化空历史。开发者也可继续用 `start.ps1 -Config` 指定私有配置。

## 验证边界

当前验证状态见 [ACCEPTANCE.md](../ACCEPTANCE.md)。独立路径恢复不等于已在第二台实体电脑完成安装与授权；真实双击入口、网页动线及线上发布分别记录，不互相代替。
