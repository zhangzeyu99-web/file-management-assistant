# 出错时怎么继续

页面按“出了什么问题 → 下一步操作”显示。已完成、待补、仅登记来源分别保留；不能修复的来源不会伪装完成。诊断信息只用于定位本次故障，不包含原始对话、凭据或文件内容。

## 本机未连接

线上阅读已有笔记不受影响。打开保存本库的电脑，双击项目目录中的 **打开工作台.cmd**，保持电脑和窗口所在进程运行，再刷新线上页面。电脑休眠或关机时任务会等待，不要重复提交。

启动器提示缺少 Python 或 Node.js 时，按 README 的运行要求安装，再双击启动。端口被其他程序占用时保留原服务；关闭重复启动的工作台后重开。不要删除锁文件强行并发写库。

## Codex 对话读取失败

- **对话过长**：打开原对话，复制需要保留的正文，到工作台 **添加资料 → 粘贴文字**，按主题分段收录。重复点击重试不会解除原生接口的长度上限。
- **缺少桌面连接**：双击启动不会创建 Codex 的会话上下文。自动读取需要 Codex 桌面正在运行，且工作台从有效的 Codex 会话中启动；这属于当前原生接口的运行条件。无需等待自动连接时，可直接使用上面的粘贴方式。
- **连接中断或超时**：先确认原对话在 Codex 桌面中能打开，保持桌面运行后重试未完成项。持续失败时改用粘贴文字，不重建增量记录。

## AI 无法整理

在项目文件夹打开终端，运行 `codex login status` 检查 Codex CLI 是否登录。未登录时运行 `codex login`，按浏览器提示完成，再重开工作台。找不到 `codex` 命令时需先安装 Codex CLI。模型超时可重试一次；同一资料持续超时，缩小选择范围或分段添加。

阅读、关键词搜索、打开现有笔记和本机迁移不依赖模型。模型未给出完整可验收结果时不登记该项成功。

## 文件无法读取

- **找不到文件**：确认文件的新位置，到 **添加资料 → 上传文件** 重新选择。
- **编码错误**：用记事本打开并另存为 UTF-8，再上传；或复制正文到 **粘贴文字**。
- **扫描 PDF**：先用 PDF 软件识别文字，再导出文本。加密 PDF 先解锁并另存副本。
- **格式不支持**：从原软件导出 TXT、Markdown、DOCX 或带文字层的 PDF；表格、音视频和图片先整理出需要保留的正文。
- **文件过大**：按章节拆分；网页上传单文件限 12 MB。
- **无权限**：关闭占用文件的程序，将资料复制到可读写的个人文件夹，再重新添加。

## 迁移失败

**预检时目标已有内容**：直接修改页面中的存放位置，选择独立、可写的空目录，点击 **检查新位置**。不要选择现有笔记库、源码或运行数据目录。

**导入过程中失败**：页面会说明文件是否已经恢复。尚未恢复时，重新选择原 ZIP 并使用新的空目录；文件已恢复但启用失败时，保留已恢复目录，使用页面的继续启用操作。不要手动覆盖当前库。

**迁移包损坏或记录不全**：回到原电脑，用最新版工作台重新导出 ZIP，再上传和预检。下载普通笔记 ZIP 不能替代包含增量记录的迁移包。

**磁盘不足**：清理目标磁盘或选择空间充足的空目录。线上迁移下载限 128 MB，较大的包请在本机网页导出；本机导入 ZIP 限 2 GiB。

**还有任务运行**：到 **更新记录** 等待结束或取消该任务，再回迁移页。上传中断或服务重启导致上传记录失效时，重新选择同一 ZIP。

## 线上连接凭据失效

此时本机阅读和资料保存可继续，线上任务和同步暂停。迁移包不携带凭据，旧电脑的 DPAPI 文件不能复制到新电脑使用。

站点所有者须从自己的发布平台取得该站点的服务访问令牌。在项目目录终端运行：

```powershell
py -3 -X utf8 configure-service.py
```

提示准备好后，输入一行 `{"token":"自己的服务访问令牌"}` 并回车。输入在 Windows 终端中隐藏，不写入命令行历史；不要发送给聊天、粘贴到网页或提交到 Git。非当前已选知识库可加 `--config "配置文件完整路径"`。完成后重开工作台并刷新线上页面。本站没有网页换令牌入口，普通阅读账号无法代替站点所有者更新它。

服务返回 403 时还需确认账号和令牌属于同一站点；返回 404 时核对站点网址和本机／线上版本；限流时等一分钟再试。请求超时后先查看更新记录，确认是否已提交，避免新建重复任务。

## 数据记录异常或仍然失败

不要删除增量记录、初始化空状态或清理运行锁。保留当前目录，从最近的完整迁移包导入到另一个空目录。没有可用备份，或同一未知错误再次出现时，将页面的 **诊断信息、错误代码和操作步骤** 提交到项目的问题反馈入口。不要附上个人笔记、迁移包、令牌或原始诊断日志。

原始异常保存在当前电脑私有运行数据目录下的 `diagnostics/`；导入失败时保存在私有迁移暂存目录下。网页和线上任务只收到可读问题、处理动作和安全诊断信息。
