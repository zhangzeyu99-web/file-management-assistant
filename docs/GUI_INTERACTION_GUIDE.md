# GUI 交互说明

GUI 是本地知识整理助手的三操作入口，负责收集输入、展示证据和打开产物。

## 首页

首页只保留三个操作：

1. 添加资料
2. 搜索回顾
3. 生成 AI 上下文包

## 添加资料

输入文本、本地文件或目录路径后点击 `添加资料`。真实路径会被扫描，可读文件会生成独立索引条目。

浏览器选择或拖放文件只记录元数据；要扫描本机目录，必须粘贴完整路径。

## 搜索回顾

搜索结果按文档结构展示：

- 一句话答案
- 命中证据
- 命中词
- 证据摘录
- 来源路径
- 下一步建议

搜索必须命中关键词或明确同义线索；无证据时显示未找到。

## 生成 AI 上下文包

先预览候选来源；确认后生成 Markdown 和 prompt。prompt 会引用来源路径和证据摘要，方便复制到新的 AI 对话。

## 文件与 Obsidian 关系

- 本地文件 / 目录目标：只作为来源被扫描和索引。
- Obsidian：写入新的整理记录、文件索引和 AI 上下文包。
- 检查本地目标：只检查路径是否存在，不改动文件。
