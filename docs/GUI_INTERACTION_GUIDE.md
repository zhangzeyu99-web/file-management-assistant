# GUI 交互说明

GUI 是本地知识整理助手的三操作入口，负责收集输入、展示证据和打开产物。

## 首页

首页只保留三个操作：

1. 添加资料
2. 搜索回顾
3. 生成 AI 上下文包

## 添加资料

输入文本、本地文件或目录路径后点击 `添加资料`。真实路径会被扫描，可读文件会生成独立索引条目。

浏览器选择或拖放文件只记录元数据；要扫描本机目录，必须粘贴完整路径。

## 搜索回顾

搜索结果按文档结构展示：

- 一句话答案
- 命中证据
- 命中词
- 证据摘录
- 来源路径
- 下一步建议

搜索必须命中关键词或明确同义线索；无证据时显示未找到。

## 生成 AI 上下文包

先预览候选来源；确认后生成 Markdown 和 prompt。prompt 会引用来源路径和证据摘要，方便复制到新的 AI 对话。
确认生成后，结果区会显示 `上下文包在 Obsidian 里怎么找`：

- `上下文包笔记`：本次生成的 Obsidian Markdown，包含来源摘要、安全边界和 prompt。
- `上下文包目录`：按任务回看或复用 prompt 的入口。
- `runtime Markdown`：本次 GUI 运行证据，用来追踪生成过程。

## 文件与 Obsidian 关系

- 本地文件 / 目录目标：只作为来源被扫描和索引。
- Obsidian：写入新的整理记录、文件索引和 AI 上下文包。
- 检查本地目标：只检查路径是否存在，不改动文件。

添加资料完成后，结果区会显示 `在 Obsidian 里怎么找`：

- `整理记录`：本次入库的主笔记，包含来源、归档建议和下一步。
- `整理目录`：按时间回看所有添加资料记录。
- `文件索引目录`：按文件名、路径或摘录关键词找每个可读文件的独立索引。
- `推荐搜索词`：来自文件名、来源路径或可读文件摘录；复制后可直接粘到 `搜索回顾`。
